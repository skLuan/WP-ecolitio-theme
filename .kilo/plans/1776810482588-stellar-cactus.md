# Make "Modelo de patinete" Field Optional

## Objective
Make the "Modelo de patinete" (Scooter model) input field optional in the Sabway battery form by:
1. Removing it from the required fields list in the AJAX validation function
2. Ensuring the form UI reflects that it's optional

---

## Analysis

### Current State
- **Form Template**: `themes/ecolitio-theme/templates/sabway-battery-form.php` (line 216-219)
  - "Modelo de patinete" is a standard text input with no visual indicator of being optional
  
- **Validation**: `themes/ecolitio-theme/inc/ajax.php` - `validate_sabway_form_data()` function (line 891-954)
  - Line 899: `'scooter_model' => __('Modelo de patinete', 'ecolitio-theme')` is in the `$required_fields` array
  - This causes validation errors if the field is empty

- **Data Processing**: The field is used in multiple AJAX handlers:
  - `ecolitio_sabway_submit_form()` (line 242-514)
  - `ecolitio_custom_batery_add_to_cart()` (line 521-687)
  
  Both sanitize and pass the field to order/cart data with `sanitize_text_field($_POST['scooter_model'] ?? '')`, which already handles empty values gracefully.

### Impact Assessment
- ✅ No frontend breaking changes - empty string is already handled
- ✅ Database/order metadata - empty strings are acceptable and already handled
- ✅ Email generation - uses null coalescing operator (`??`), so empty values show as 'N/A'
- ✅ No dependent functionality relies on this field being mandatory

---

## Implementation Plan

### Task 1: Update Validation Function
**File**: `themes/ecolitio-theme/inc/ajax.php`
**Location**: Lines 895-903 in `validate_sabway_form_data()` function

**Change**: Remove `'scooter_model'` from the `$required_fields` array

```php
// BEFORE:
```
