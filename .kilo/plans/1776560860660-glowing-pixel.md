# Plan: Add `cantidad_motores` to Cart/Checkout Display & Remove Liters References

## Overview

Two goals:
1. **Remove all "liters/litros" references** from `functions.php` (cart display + order save hooks) and replace the external-battery branch with a clean no-dimension fallback.
2. **Add `cantidad_motores` as a visible display row** in the cart item data and the order line item meta (in `functions.php`), so it appears in cart, checkout review, order confirmation, and emails.

The form HTML (`sabway-battery-form.php`), `formController.js`, and `ajax.php` already handle `cantidad_motores` correctly — no changes needed there.
