# Plan: Call swiper.update() after dimensions container visibility change

## Problem
When the battery location toggle switches between "Interna" and "Externa", the `#dimensions-container` element is shown/hidden using the `collapsed` CSS class. Because the DOM dimensions change (height goes from 0 to auto), Swiper doesn't recalculate the slide height and ends up clipping/cutting content.

## Solution
Call `swiperSab()?.update()` at the end of `applyLocationState()` in `formController.js`. This triggers Swiper to recalculate all slide heights and update its layout.

## Context

### Relevant files
- `themes/ecolitio-theme/src/formController.js` — contains `applyLocationState` (lines 649–668)
- `themes/ecolitio-theme/src/main.js` — exposes `swiperSab()` accessor (line 35–37)

### Already available
`swiperSab` is already imported at line 1 of `formController.js`:
```js
import { nextSlide, swiperSab } from "./main";
```

## Change

**File:** `themes/ecolitio-theme/src/formController.js`  
**Location:** End of `applyLocationState`, after the `if/else` block (around line 663), before the `uiManager.toggleConfirmationRow` calls — or after them, it doesn't matter as long as it's after DOM changes are applied.

**Add this line at the very end of `applyLocationState`, after all DOM changes:**
```js
swiperSab()?.update();
```

### Full before/after diff

**Before (lines 649–668):**
```js
const applyLocationState = (value) => {
  if (!dimensionsContainer) return;
  const isInternal = value === 'Interna';
  if (isInternal) {
    dimensionsContainer.classList.remove("collapsed");
  } else {
    dimensionsContainer.classList.add("collapsed");
    // Clear dimension inputs when hiding
    const alto = document.getElementById("alto-bateria");
    const ancho = document.getElementById("ancho-bateria");
    const largo = document.getElementById("largo-bateria");
    if (alto) alto.value = '';
    if (ancho) ancho.value = '';
    if (largo) largo.value = '';
  }
  // Show/hide dimension rows in confirmation step
  uiManager.toggleConfirmationRow("altocm", isInternal);
  uiManager.toggleConfirmationRow("anchocm", isInternal);
  uiManager.toggleConfirmationRow("largocm", isInternal);
  uiManager.updatesumary();
};
```

**After:**
```js
const applyLocationState = (value) => {
  if (!dimensionsContainer) return;
  const isInternal = value === 'Interna';
  if (isInternal) {
    dimensionsContainer.classList.remove("collapsed");
  } else {
    dimensionsContainer.classList.add("collapsed");
    // Clear dimension inputs when hiding
    const alto = document.getElementById("alto-bateria");
    const ancho = document.getElementById("ancho-bateria");
    const largo = document.getElementById("largo-bateria");
    if (alto) alto.value = '';
    if (ancho) ancho.value = '';
    if (largo) largo.value = '';
  }
  // Show/hide dimension rows in confirmation step
  uiManager.toggleConfirmationRow("altocm", isInternal);
  uiManager.toggleConfirmationRow("anchocm", isInternal);
  uiManager.toggleConfirmationRow("largocm", isInternal);
  uiManager.updatesumary();
  // Notify Swiper to recalculate slide height after DOM change
  swiperSab()?.update();
};
```

## Why this works
`swiper.update()` recalculates sizes, updates pagination, and re-renders the slider — handling the height change caused by expanding/collapsing the dimensions container inside the active slide.
